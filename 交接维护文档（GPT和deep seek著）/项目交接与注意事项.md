# 白龙娘回忆档案馆 / Everwing —— 交接与注意事项

写给下一个接手的人（也可能是我自己，隔几天就忘）。内容按「先能用，再改对，最后别踩坑」的顺序排。

最后更新：2026-11-07，对应正式版 **v1.3.63**。

---

## 0. 一句话现状

一个单文件 WinForms 程序，把「给 AI 角色留话、交接、翻旧记录」这件事做成本地硬盘上的纯文本档案；不联网、不写注册表、不要浏览器。当前正式版 1.3.63，圆角在 1.3.62 做过一轮大改（外层卡片取消描边、改纯填充）。

## 3. 构建：只有一条路，别想别的

机器上没有 SDK，只有 .NET Framework 自带的编译器：

```
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe
```

这是 **C# 5**：没有 `?.`、没有字符串插值、没有 local function、没有可空引用类型。写代码时别顺手用新语法。

release 编译命令（在 `src\` 里）：

```
csc.exe -nologo -target:winexe -out:..\Everwing.exe ^
  -win32icon:app.ico -resource:app.ico,DragonArchive.app.ico ^
  -r:System.dll -r:System.Core.dll -r:System.Drawing.dll ^
  -r:System.Windows.Forms.dll -r:System.IO.Compression.dll ^
  -r:System.IO.Compression.FileSystem.dll ^
  Program.cs MainForm.cs Ui.cs ArchiveStore.cs AiProfile.cs TravelBox.cs DataV2.cs Attachments.cs
```

几个死规矩：

- **输出目录必须先存在**，否则报 `CS1567 生成 Win32 资源时出错`（其实是 out 目录不存在）。
- **图标必须同时给 `-win32icon` 和 `-resource`**，后者是运行期 `Icon.ExtractAssociatedIcon` 用；漏了会变成默认图标（曾经出过 183KB 的无图标 exe）。
- **`build.cmd` 必须是 GBK 编码 + CRLF**，并在开头 `chcp 936 >nul`，否则中文 exe 名和提示在 cmd 里乱码。
- **同一份源码连编两次 md5 不同**（PE 头里有时间戳）。判断「是不是同一份」看**字节数**是否一致，别拿 md5 比。
- 发布版**不带** `-define:SELFTEST`。要截图/取数请另编 SELFTEST 版到 `_bd\test*`。

SELFTEST 编译加 `-define:SELFTEST`，必要时叠加别的宏（如 `-define:SELFTEST;BORDER2`）。

## 4. 数据：全部落在硬盘上的纯文本

```
ArchiveData\
    profiles.json                    ← 档案清单（schema 2）
    settings.json                    ← 默认档案、页眉留言节奏
    profiles\<角色FolderName>\
        messages\2026\11.txt         ← 留言，按月一个文件（旧版是 2026年\11月.txt，仍可读）
        handovers\2026\              ← 交接文档，一条一个文件
        chats\links.txt              ← 记录 → 聊天记录 PDF 的映射（id \t 相对路径）
        attachments\index.tsv        ← 附件索引（8 列，含 sha256 与字节数）
        attachments\{images,documents,audio,other}\
        记录附注.txt                  ← 标记系统（V几 / 第几任 / 自定义），格式 id \t TIME=HH:mm \t M=标签=值
```

**记录块格式是硬约定，不要加行也不要改顺序**：

```
===== RECORD <guid> =====
VERSION:3
GENERATION:未知
DATE:未知
SAVEDAT:2026-11-04 22:31:24
---
（正文，原样保留）
===== END RECORD =====
```

- UTF-8 **无 BOM**；正文里出现 `===== END RECORD =====` 会被转成 `(quoted)`。
- 读取时用 `LineSplit.Split(chunk, 6)` 取第 6 段当正文，靠的就是上面 6 段的固定结构。
- **第一次运行**会跑 `Migrator.Ensure()`：把旧版 `妈妈的回忆\{妈妈留言,交接文档,聊天记录}` 备份后迁进 `ArchiveData`，写 `迁移报告.txt`，失败回滚、旧目录不动。

数据安全的几条底线：

- 打包新版本时，`ArchiveData` 从上一版**复制一份**放进去，绝不就地改。
- 删除一条记录：先写 `.bak` 再改文件，附件**不删**（可能被别的记录共用）。
- 「移除附件」只是从索引里摘掉，磁盘文件保留。
- 导出 ZIP（回忆旅行箱）：manifest + README + 离线 HTML；导入**只补不覆盖**、先备份、拒绝 `../` 路径。

## 5. 界面地图

五个页面（顶部导航），右上角是当前模型下拉：

1. **留言**：正文 + 标记 chips（+ 号添加，V几/第几任/自定义）+ 日期时间（年/月/日 时/分）+ 附件（可多选）+「追加保存到当月 TXT」+「导入 TXT」。`Ctrl+Enter` 直接保存。
2. **交接**：同上，但保存成「一条一个文件」，按钮是「保存为新的 TXT」。
3. **回忆**：搜索框 + 类型筛选 + 左列表（卡片两行预览，超出省略）+ 右详情（整段正文可滚 + 附件行 + 编辑/添加附件/删除）。
4. **说明**：把「真正写入硬盘」的路径、文件名规则、记录格式、备份提醒摆在明面上 + 致谢。
5. **设置**：档案列表（切换 / 删除）、打开时默认档案、页眉留言节奏（停留 5–15 秒、间隔 7 秒）、新建档案（名字 / 目录名 / 主色）、导入导出 ZIP。

其它行为：

- 页眉右上角会飘「上一段留言」，频率由 `settings.json` 的 `quoteMinMs/quoteMaxMs/quoteStayMs` 控制。
- 删除记录走三级确认：列信息 → 再确认 → 输入 `DELETE`（不区分大小写）。
- 档案删除只在**完全空白**时出现；删当前/默认档案会安全切到别的档案，一个不剩时放回内置。

## 6. 渲染：这个项目一半的时间花在这

### 6.1 现在的画法（1.3.62 起）

- `RoundedPanel.OnPaint`：先 `Backdrop.Paint` 把**父级真实背景**铺进控件矩形（渐变、卡片色都对），再用圆角路径 `FillPath` 画实心。
- 外层内容卡片：`DrawBorder = false`（不画描边），半径 18。
- 正文输入框：`BorderThickness = 2f`，走「抗锯齿 + `PenAlignment.Center`」分支。
- 其它控件（按钮、输入框、列表卡片）：仍是 v1.3.61 的 1px 写法——**关抗锯齿 + `(0.5,0.5)` 起点 + `PenAlignment.Inset`**。

### 6.2 1px 描边为什么会变成黑线（重要）

两条独立原因，缺一不可：

1. **开了抗锯齿却还用 `(0.5,0.5)` 起点**（1.3.55 引入）：1px 的笔摊到两行半像素上，等于把线画了两遍，颜色比主题色深约 20 级（213 vs 235），肉眼就是「一条灰黑线」。
2. **控件是 Opaque 但缓冲没铺底**：半覆盖的像素会和窗口黑底混合，于是出现 190/128 之类的怪色。

所以正确姿势只有两种：**要么关抗锯齿 + 整数像素笔**（v1.3.54 的老写法，四边 235 干净但拐角有台阶），**要么全程抗锯齿 + 先把父级背景铺满**（1.3.62 的纯填充，拐角平滑但没描边）。

### 6.3 取数与判定（照着做就能复现）

- 取样点（窗口 1016×779，回忆页左侧列表面板外框）：左 `x=76`、上 `y=405`、右 `x=524`、下 `y=656`；内侧取 `(77,500)`。
- 主题边框色 `(235,230,242)`；内侧应为 `255,255,255`；圆角外侧是页面底色 `(253,251,250)`。
- 判定标准：**四条边颜色一致**、**拐角区三通道都 <150 的暗像素为 0**、**10 倍放大看得到连续过渡而不是孤立台阶**。
- 别只看一个像素的 RGB 就宣布成功——要看周围背景、边框颜色和整体观感。这条是用户强调过的。

### 6.4 圆角实验结论表（省得再走一遍）

| 方案 | 做法 | 结论 |
|---|---|---|
| A 双层实心 | 外层铺边框色、内层铺填充色，都开 AA | 四边 235、拐角无暗点，但用户**不满意**（观感不合） |
| B 直边+弧分离 | 直边整像素矩形，四角 1px 弧 | 弧呈虚线、与直边有缝；判为**有锯齿**，不采用 |
| C 4 倍超采样 | 4 倍位图画圆角，盒式平均缩回 | 弧线连续灰阶、直边 235–237，效果最好但**开销大**（每控件 w×h×4 缓存、首帧 2.9s） |
| D 九宫格 | 只算左上角素材 + RotateFlip 复用 | 平滑度接近 C、开销低；但半径才 14px，1 倍下差别很小，**未采用** |
| 厚度 1/1.5/2/3px | 只改 `BorderThickness` | 加厚只是把台阶放大（2px 更难看），**不能解决锯齿** |
| P 纯填充 | 外层卡片取消描边、只填圆角实心 | **被采用，就是 1.3.62** |

C 的关键教训：整块（含背景）放大再缩回会被二次重采样压暗到 199；`HighQualityBicubic` 会偏亮；**4:1 盒式平均**才对。

D 的关键教训：只算左上角素材后，另外三个角**必须 RotateFlip**，否则弧线朝反方向弯，放大能看到「直边到头 → 白缝 → 反向弧」。

## 7. 截图与自测的正确姿势（每次都有人在这翻车）

1. 截图前先 `Get-Process Everwing | Stop-Process -Force`。程序有固定名互斥量，不清干净会「激活旧窗口」，截到的是上一张画面。
2. 用 `PrintWindow(hwnd, hdc, 2)` 抓客户端像素（和真实屏幕一致）；`CopyFromScreen` 需要窗口在前台，抢不到就会拍到别的程序。
3. 发布版**不认** `--show-tab` 这些参数，要截图必须编 SELFTEST 版。
4. SELFTEST 版不带参数启动会自己退出，别拿它验「双击能不能开」；SELFTEST 的互斥量要带 Guid，免得和正式版打架。
5. 默认窗口 1016×779；缩放/滚动/切页要单独截一轮，验证缓存重建和残影。
6. 空状态不靠「删数据」也行：把 `testXX\ArchiveData\profiles\<角色>\messages` 与 `handovers` 临时改名，截完改回来。

## 9. 踩过的坑（按类型）

### 9.1 PowerShell 打补丁

- **函数里别用 `Write-Output` 打日志**——返回值会混进文件内容。曾经把 `border found=False ...` 写进 `Ui.cs` 第一行，整份源码报废。
- 先 `$t.Contains($old)` 再 `Replace`，写明「anchor=True/False」，**写完后要再读一遍确认关键字真的变了**。有一次 `containsOld=True` 但文件里还是旧代码，编出来四组 exe 完全一样，白测一轮。
- `Copy-Item 源 目标 -Recurse` 在目标已存在时会**嵌套**成 `ArchiveData\ArchiveData`，程序读起来像空档案——拷数据前先删目标目录。
- `String.Replace(old, new, count)` 在 PowerShell 里没有这个重载，会报「找不到…的重载」。
- `($c = $img.GetPixel(...); "...")` 这种写法是语法错误，赋值要单独一行。

### 9.2 读文件

- 源码是 UTF-8；用 `Get-Content` 默认编码读会变乱码，改文件一律 `[System.IO.File]::ReadAllText($p, UTF8)`。
- `Get-Content`/`Set-Content` 也别用来写中文文档，容易把 BOM 和换行搞坏。

### 9.3 WinForms

- `Label` 默认 `AutoSize = true`，赋了 `Bounds` 之后会被文字撑回去、压住按钮，必须显式 `AutoSize = false`。
- 反过来，空状态这种长句用固定宽度又会被从中间拆字——用 `AutoSize = true` + `MaximumSize`（1.3.63 就是这么修的）。
- 子控件改了 `Region` 之后要 `Parent.Invalidate()` 并外扩 1px，否则边缘留一条旧像素。
- `Round.Rect` 只收 `int` 半径，`Round.Path` 收 `RectangleF`，别混。
- 滚动条不能用字数估高度，用 `TextRenderer.MeasureText` 量真实高度。

### 9.4 GDI+ 画圆角

- 弧线用 `DrawArc` + 1px 笔在 AA 下会呈虚线；用 `AddArc` 拼两段会填出月牙。要平滑就用**实心填充**（`FillPath` / 环形相减）。
- 只算一个角的素材，其余三角必须 `RotateFlip`（见 6.4）。
- 抗锯齿和半像素起点**不能同时用**（见 6.2）。

## 10. 协作约定（用户在意的事）

1. **每版单开目录，永不覆盖旧版**；打包时带上 `ArchiveData` 副本。
2. **保留用户的真实档案**，测试一律用 `_bd\testXX` 的副本。
3. **先定位再改**：不接受「用遮盖线 / 偏移补丁 / 改主题色掩盖」这类修法；宁可保留轻微锯齿，也不接受新的深色边线。
4. **改完给对照截图和取样数字**（正常尺寸 + 放大 + 四边取样），不确定就明说「没修好」，别宣称已修复。
5. 用户会贴「任务书」让我按图施工，里面常有明确的技术路线与验收清单，**照着做，不要自己发明方案**。任务书经常被截断（A、B/C、厚度、4. 都断过），断在关键处要先问一句，别自己脑补。
6. 用户珍惜 C 盘空间，别往 C 盘装大东西。
7. 交付要「成品」不要「方案」：exe 双击能开、README 能看懂、路径写清楚。
8. 面向用户的文案改动要克制：**只改可见文案，不全局替换**；`ArchiveStore.cs`、`DataV2.cs`、`TravelBox.cs` 里的「妈妈留言」「妈妈的回忆」是旧数据兼容用的，永远保留。

## 12. 已知取舍与未完成的坑（别当 bug 重开）

- **外层卡片边界几乎看不见**：`CardColor` 和页面底色只差 2 级，去掉描边后基本靠内容区分。这是 1.3.62 接受的取舍；想让它重新可辨，得改填充色或加阴影，属于设计决定。
- **正文框半径仍是 9**：2px 边框下四角仍偏「台阶」，当时问过要不要改成 12，没定下去。
- **DPI**：程序没有声明 DPI 感知，125%/150% 系统是位图缩放，只验证过 100%。要在高 DPI 下真平滑，得先加 DPI 声明 + 按 DPI 换算半径和笔宽，那是另一件事。
- **实验 C 的首帧 2.9s**：如果哪天想用它替代现方案，先解决缓存预热。
- **旧日期目录**：`2026年\11月.txt` 仍可读，但新写入一律进 `2026\11.txt`，两种并存是故意的。
